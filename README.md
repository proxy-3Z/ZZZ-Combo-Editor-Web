# ZZZ Combo Editor

ゼンゼロにおけるスキル回しを、タイムラインとして配置し可視化するための非公式ファンメイドツールです。

## ZZZ Combo Editor

GitHub Pages:

https://proxy-3Z.github.io/ZZZ-Combo-Editor-Web/

## 主な機能

- タイムライン形式のコンボ作成
- スキルのドラッグ＆ドロップ配置
- エージェントごとのスキルレベル設定と倍率の反映
- ダメージ倍率とブレイク倍率の合計表示
- ブラウザ内へのプリセット保存および読み込み
- 共有コードの発行と読み込み


## 段別スキル・共有コードの注意事項

- プロメイア・エレン・月城柳の段別8スキル・13倍率系列に対応しています。月城柳は上弦／下弦を切り替えられ、構え未選択のノードは未計算として表示します。
- 各攻撃段のDamage／Break倍率を段全体の合計として、ノード1個につき1回加算します。これは本ツールの計算仕様で、ゲーム内挙動の実測を意味しません。
- 構えを含む共有コードはShare v4を使用します。旧アプリでは読み込めないため、公開版を更新・再読み込みしてから利用してください。旧v1〜v3の読み込みは維持しています。
- 暫定timing（PLACEHOLDER）は実測モーション時間ではありません。ノードの時間幅・配置の目安として利用してください。

## 参照元

スキル倍率などのゲームデータの確認・更新にHoYoWikiの公開情報を参照しています。一部の倍率には、照合・承認したZenlessDataの値を採用しています。

各種データは開発時に取得し、静的データとしてアプリケーションに組み込んでいます。本ツール利用時に、ユーザーのブラウザからHoYoWikiへ直接アクセスする仕組みではありません。

## 開発・設計

このサイトはReact、TypeScript、Viteを使用した静的Webアプリケーションで、主要な機能はブラウザ上で動作します。

開発用リポジトリにはデータ生成・更新用ツール等が含まれるため、現在ソースコード全体は公開していません。

## エレンP3・シード追加スキルの注意事項

- エレンP3の敵サイズ別倍率（小型／中型／大型）と入力条件（クイック／チャージ）の選択に対応しています。
- シード901の「通常攻撃：落花・崩墜Ⅰ／Ⅱ」を、それぞれ独立したSkillとして配置できます。Ⅰの配置でⅡを自動追加・加算することはありません。
- 敵サイズの選択を含む共有コードはShare v5を使用します。古い公開アプリではShare v5や新しいSkill IDを復元できないため、最新版への再読み込みが必要な場合があります。旧Share v1〜v4の読み込み互換性は維持しています。
- モーション時間は暫定値を含み、実測時間とは限りません。
- 倍率にはHoYoWiki・ZenlessData等の外部公開情報を参考にした加工済みデータが含まれます。正確性・最新性を保証するものではありません。
