# ZZZ Combo Editor

ゼンゼロにおけるスキル回しを、タイムラインとして配置し可視化するための非公式ファンメイドツールです。

## ZZZ Combo Editor

GitHub Pages:

https://proxy-3Z.github.io/ZZZ-Combo-Editor-Web/

## 主な機能

- タイムライン形式のコンボ作成
- スキルのドラッグ＆ドロップ配置
- エージェントごとのスキルレベル設定と倍率の反映
- ダメージ倍率とブレイク倍率の合計表示
- ブラウザ内へのプリセット保存および読み込み
- 共有コードの発行と読み込み

## 参照元

スキル倍率などのゲームデータの確認・更新にHoYoWikiの公開情報を参照しています。

各種データは開発時に取得し、静的データとしてアプリケーションに組み込んでいます。本ツール利用時に、ユーザーのブラウザからHoYoWikiへ直接アクセスする仕組みではありません。

## 開発・設計

このサイトはReact、TypeScript、Viteを使用した静的Webアプリケーションで、主要な機能はブラウザ上で動作します。

開発用リポジトリにはデータ生成・更新用ツール等が含まれるため、現在ソースコード全体は公開していません。
